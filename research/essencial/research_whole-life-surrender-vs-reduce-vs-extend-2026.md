# 종신보험 해지 vs 감액완납 vs 연장 손익 3종 비교 (2026) — 리서치 노트

## 개요
- 비교 대상: ① 해지 ② 감액완납 ③ 연장정기보험
- 기준 시점: 2026년 5월
- 시뮬레이션 기준: 50세 가입 15년차·월 30만원 납입·사망보험금 1억·해지환급금 4,000만원

## 핵심 사실 — 3가지 선택지

### 1. 해지 (Surrender)
- 누적 해지환급금 즉시 수령
- 사망보장 즉시 0원
- 특약 즉시 소멸
- 7년 미만 해지 시 환급률 80% 미만 (사업비·위험보험료 차감)
- 10년 이상 시 환급률 100% 근접
- **장점**: 즉시 자금 확보 / **단점**: 보장 완전 상실

### 2. 감액완납 (Reduced Paid-up)
- 더 이상 보험료 납입 X
- 누적 해지환급금을 일시납 보험료로 간주 → 사망보장 축소 유지
- 보장 기간: 종신 그대로
- 사망보험금: 약 30~50% 수준으로 축소 (보험사·약관별 차이)
- 특약 소멸
- **장점**: 보험료 부담↓ + 평생 보장 / **단점**: 보장금액 대폭 축소

### 3. 연장정기보험 (Extended Term)
- 더 이상 보험료 납입 X
- 사망보험금 1억 유지
- 보장 기간만 단축 (예: 종신 → 65~70세 만기)
- 특약 소멸
- **장점**: 사망보장 풀 유지 / **단점**: 특정 시점 후 무보장

### 4. (참고) 연금전환
- 해지환급금을 연금보험으로 전환 (월 일정금 수령)
- 노후 자금 활용 의향이면 검토

## 시뮬레이션 (50세 가입 15년차)

**전제**: 월 30만원 × 15년 = 누적 납입 5,400만원, 해지환급금 4,000만원, 사망보험금 1억

| 옵션 | 즉시 수령 | 사망보장 (당장) | 보장 기간 | 특약 | 환급률 |
|------|---------|--------------|---------|------|------|
| **해지** | 4,000만원 | 0원 | 즉시 종료 | 소멸 | 74% (5,400→4,000) |
| **감액완납** | 0원 | 약 3,000~4,000만원 | 종신 | 소멸 | — |
| **연장정기** | 0원 | 1억 유지 | 약 75~80세 만기 | 소멸 | — |
| (참고) **유지** | 0원 | 1억 유지 + 향후 환급금 증가 | 종신 | 유지 | 향후 100%+ |

## 시점별 비교 (가입 후 경과 연수에 따라)

### 가입 5년차 (해지환급률 약 50%)
- 해지: 손실 큼 (납입 1,800만 → 환급 900만)
- 감액완납: 가능하지만 보장 축소 폭 큼 (사망보험금 1,000만 수준)
- 연장정기: 가능하지만 보장 기간 짧음 (60대 중반까지)
- **권장**: 가급적 유지 또는 일시 납입 중단

### 가입 15년차 (해지환급률 약 75%)
- 해지: 4,000만원 즉시 확보, 일부 손실
- 감액완납: 사망보장 3,000~4,000만 종신 유지
- 연장정기: 사망보장 1억 + 75~80세까지 유지
- **권장**: 보장 필요 여부 + 자금 필요 여부에 따라 결정

### 가입 25년차 이상 (해지환급률 100%+)
- 해지: 5,000만+ 환급금 + 이자 수령
- 감액완납: 사망보장 5,000만~7,000만 종신
- 연장정기: 1억 + 90세 이상까지 유지 가능
- **권장**: 노후 자금 필요면 연금전환 검토

## 시나리오별 추천

1. **자금 즉시 필요 + 보장 불필요 (자녀 독립 완료·연금 충분)** → 해지
2. **보험료 부담↓ + 평생 사망보장 유지** → 감액완납 (배우자 보장 우선)
3. **사망보장 풀 유지 + 60~70대 보장 충분** → 연장정기 (자녀 학자금·주택 대출 보장)
4. **65세 이상 + 노후자금 필요** → 연금전환
5. **5년 미만 + 보험료 부담** → 일시 납입 중단(자동대출 납입) 또는 감액

## 손익 계산 핵심 변수

| 변수 | 영향 |
|------|------|
| **가입 경과 기간** | 짧을수록 해지 손실 큼 (사업비 차감) |
| **현재 해지환급률** | 7년 미만 80% 미만, 15년+ 90%+ |
| **사망보장 필요성** | 부양가족·대출 등 |
| **재정 상황** | 매월 보험료 부담 vs 일시 자금 확보 |
| **특약 가치** | 특약(의료비·암 등) 별도 가입 필요 시 추가 비용 |
