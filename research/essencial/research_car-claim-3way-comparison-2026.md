# 자차보험 처리 vs 상대보험 처리 vs 자비수리 3종 비교 (2026) — 리서치 노트

## 개요
- 비교 대상: ① 자차보험(본인 자차로 처리) ② 상대보험(상대 대물로 처리) ③ 자비수리(보험 미처리)
- 기준 시점: 2026년 5월
- 핵심 변수: 과실비율, 손해액 규모, 본인 연 보험료, 무사고 할인 누적

## 3가지 처리 방식 핵심 비교

### 1. 자차보험 (자기차량손해담보)
- 본인 차량 수리비를 본인 보험사가 보상
- 자기부담금: 손해액의 20% (계약에 따라 30% 선택 가능), **최소 20만원 ~ 최대 50만원**
- 사고 기록 1건 등록 → 3년간 할증
- 할증률: 약 12% 인상 + 무사고 할인(약 8%) 상실 = 실질 약 20%/년 추가
- 연 보험료 70만원 기준 → 3년 추가 약 42만원 + 자기부담금 = 총 부담

### 2. 상대보험 (상대방 대물배상)
- 상대 과실이 있을 때 상대방 보험사에 본인 차 수리비 청구
- **본인 부담금 0원** (과실비율에 따라 일부 부담)
- 본인 사고 기록 없음, 본인 보험료 할증 없음
- 과실 100% 상대 → 본인 100% 보상
- 과실 50:50 → 양쪽 자차로 처리 → 둘 다 기록 등록
- 차량 시세(보험가액) 한도

### 3. 자비수리 (보험 미처리)
- 본인 직접 정비소에서 수리비 부담
- 보험사 통과 없음 → 사고 기록 없음, 할증 없음
- 무사고 할인 누적 유지
- 즉시 전액 부담 필요

## 처리 선택 의사결정 플로우

```
사고 발생
    ├── 상대 과실 50%+ → 상대보험으로 본인 차 수리 (본인 부담↓)
    │       └── 과실비율 협의·확정 후 진행
    │
    ├── 본인 100% 과실
    │       ├── 수리비 ≤ 손익분기점(약 60~80만원) → 자비수리
    │       └── 수리비 > 손익분기점 → 자차보험 (자기부담금 + 할증 < 수리비)
    │
    └── 단독 사고 (전봇대·연석 등) → 자차보험만 가능 (상대 없음)
            └── 손익분기점 기준 자차 vs 자비
```

## 손익분기점 계산 (자차 vs 자비)

**손익분기점 = 자기부담금 + 3년 할증 추가비용**
- 연 보험료 40만원: 20만 + (40만×20%×3년) = 44만원
- 연 보험료 70만원: 20만 + (70만×20%×3년) = **62만원** (대표 사례)
- 연 보험료 100만원: 20만 + (100만×20%×3년) = 80만원

**수리비가 위 금액보다 작으면 자비, 크면 자차 보험처리가 유리합니다.**

## 환입 제도 (보험금 반환)

자차보험 처리 후 손익 재계산 시 자비가 나은 경우:
- 갱신일 3개월 이전까지 환입 신청 → 받은 보험금 반환 → 사고 기록 삭제 + 할증 면제
- 단, 갱신일 임박 시 불가능 (각 보험사 약관 확인 필수)
