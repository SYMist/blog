# 증여세 vs 상속세 미리 계산 — 부모 60대 어느 게 유리한가 (2026) — 리서치 노트

## 개요
- 비교 대상: 사전 증여 vs 사후 상속 (부모 60대 → 자녀 이전)
- 기준 시점: 2026년 5월
- 시뮬레이션 기준: 자녀 2명·자산 규모 5억·10억·20억·30억·50억 5종 비교

## 핵심 사실 — 세율·공제

### 1. 공통 세율 (5단계 누진, 상속세·증여세 동일)
| 과세표준 | 세율 | 누진공제 |
|---------|------|---------|
| 1억원 이하 | 10% | — |
| 1억~5억원 | 20% | 1,000만원 |
| 5억~10억원 | 30% | 6,000만원 |
| 10억~30억원 | 40% | 1억 6,000만원 |
| 30억원 초과 | 50% | 4억 6,000만원 |

### 2. 증여세 공제 (10년 누계)
| 증여자 → 수증자 | 공제 한도 |
|----------------|---------|
| 배우자 → 배우자 | 6억원 |
| 직계존속 → 직계비속 (성인) | **5천만원** |
| 직계존속 → 직계비속 (미성년) | 2천만원 |
| 직계비속 → 직계존속 | 5천만원 |
| 기타 친족 (6촌·4촌 인척 등) | 1천만원 |

10년 누계 기준이므로, 60세에 5천만원 증여 → 70세에 다시 5천만원 증여 가능 → 80세 5천만원 → 90세 5천만원. 자녀 2명·30년 분할 시 1인당 1억 5천만원·총 3억원 비과세 가능.

### 3. 상속세 공제
| 공제 항목 | 한도 |
|----------|------|
| **일괄공제 (기초+인적공제 합계 중 큰 금액)** | **5억원** |
| 배우자 상속공제 | 최소 5억 ~ 최대 30억 |
| 자녀공제 (현행) | 1인당 5천만원 |
| 자녀공제 (개정안 검토 중) | **1인당 5억원으로 상향** |
| 동거주택 상속공제 | 6억원 |
| 금융재산공제 | 최대 2억원 |

배우자 + 자녀 2명 + 자산 10억 케이스에서 현행 일괄공제 5억 + 배우자공제 5억 = 10억 공제 가능.

## 자산 규모별 시뮬레이션 (자녀 2명 균등, 배우자 없는 단신 부모 가정)

### 시나리오 A: 자산 5억원
- **사전 증여**: 각 2.5억 - 5천 = 2억 과세표준 × 20% - 1천 = 3천만 × 2 = **6,000만원**
- **상속**: 일괄공제 5억 → 과세표준 0 → **0원**
- **→ 상속이 압도적 유리 (6,000만원 절감)**

### 시나리오 B: 자산 10억원
- **사전 증여**: 각 5억 - 5천 = 4.5억 × 20% - 1천 = 8천만 × 2 = **1억 6,000만원**
- **상속**: 일괄공제 5억 → 과세표준 5억 × 20% - 1천 = **9,000만원**
- **→ 상속이 유리 (약 7,000만원 절감)**

### 시나리오 C: 자산 20억원
- **사전 증여**: 각 10억 - 5천 = 9.5억 × 30% - 6천 = 2.25억 × 2 = **약 4.5억원**
- **상속**: 일괄공제 5억 → 과세표준 15억 × 40% - 1.6억 = **약 4.4억원**
- **→ 거의 동률** (사전 증여가 약간 더 부담)

### 시나리오 D: 자산 30억원
- **사전 증여**: 각 15억 - 5천 = 14.5억 × 40% - 1.6억 = 약 4.2억 × 2 = **약 8.4억원**
- **상속**: 일괄공제 5억 → 과세표준 25억 × 40% - 1.6억 = **약 8.4억원**
- **→ 거의 동률**

### 시나리오 E: 자산 50억원
- **사전 증여**: 각 25억 - 5천 = 24.5억 × 40% - 1.6억 = 약 8.2억 × 2 = **약 16.4억원**
- **상속**: 일괄공제 5억 → 과세표준 45억 × 50% - 4.6억 = **약 17.9억원**
- **→ 사전 증여가 약간 유리** (10년 분할 시 추가 절감 가능)

## 손익분기·전략

| 자산 규모 | 추천 전략 |
|---------|---------|
| 5억 이하 | 상속 (일괄공제 5억으로 0원 또는 최소) |
| 5억~10억 | 상속 유리 (약 7,000만원 절감) |
| 10억~30억 | 거의 동률 — 자산 증가율·증여 시기 따라 결정 |
| 30억 이상 | 사전 증여 분산 (10년 누계 공제 + 자산 증가분 분리) |
| 50억 이상 | 사전 증여 압도적 유리 (10년 분할 + 미래 자산 분리) |

## 사전 증여의 숨겨진 이점

1. **자산 증가분 분리**: 증여 후 가치 상승분은 자녀 자산이 되어 상속재산에서 제외
2. **10년 누계 공제 재활용**: 60→70→80→90세 4회 증여 → 1인당 2억원 비과세 가능
3. **사망 직전 10년 이내 증여**: 상속재산에 합산되어 절세 효과 사라짐 → 60대 일찍 시작이 핵심
4. **부동산 증여**: 시점에 따라 평가가액 활용 가능 (공시가격 변동기)

## 상속의 숨겨진 이점

1. **일괄공제 5억 + 배우자공제 5억+ = 최소 10억 비과세**
2. **자녀공제 개정안**: 1인당 5억으로 상향 시 자녀 3명이면 +15억 추가 공제
3. **동거주택 상속공제**: 부모 1주택 자녀 동거 10년 → 6억 추가 공제
4. **상속세 분납·연부연납**: 5년·10년·15년 분할 납부 가능 (이자 발생)

## 60대 부모의 실용적 결정 동선

```
부모 자산 규모 확인
    ├── 5억 이하 → 상속 그대로 (일괄공제 5억으로 0원)
    │
    ├── 5억~15억
    │       └── 상속 그대로 (자녀공제 개정안 확인 후 추가 판단)
    │
    ├── 15억~30억
    │       ├── 자녀가 부동산 보유·소득 충분 → 상속
    │       └── 자녀가 자금 필요 시기 (결혼·주택) → 일부 사전 증여
    │
    └── 30억+
            ├── 60대 일찍 → 사전 증여 10년 분할 시작
            └── 70대 이후 → 사전 증여 효과 제한 (사망 직전 10년 합산)
```
