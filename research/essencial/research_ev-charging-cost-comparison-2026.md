# 전기차 가정충전 vs 공공충전 vs 급속충전 비용 시뮬레이션 (2026) — 리서치 노트

## 개요
- 비교 대상: 가정 심야 / 가정 일반 / 공공 완속 / 공공 급속 / 민간 급속(비회원) — 5개 옵션
- 기준 시점: 2026년 5월
- 시나리오: 연 1만 5천km · 평균 전비 5.5km/kWh · 월 약 227kWh 충전 (코나 일렉트릭/아이오닉5/EV6 평균)

## 핵심 사실 — 5종 충전 옵션 단가

### 1. 가정 심야 충전 (별도 계량기 + 시간대별 요금제)
- 한전 전기차 심야 충전요금 (별도 계량기 설치 시): **약 60~80원/kWh** (23시~9시 적용)
- 충전기 설치 비용: 콘센트형 30~80만원 / 7kW 벽걸이형 100~150만원 (보조금 일부 가능)
- 적용 조건: 단독주택·아파트 전용 구역(개인 충전기) + 한전 전용 계량기 신청
- 약점: 아파트는 입주자 동의·관리사무소 협의 필요 + 콘센트 위치 제약

### 2. 가정 일반 충전 (한전 주택용 누진제)
- 2026년 5월 한전 주택용 전기요금:
  - 1단계 (200kWh 이하): 약 120원/kWh
  - 2단계 (201~400kWh): 약 214.6원/kWh
  - 3단계 (400kWh 초과): 약 313원/kWh
- 일반 가정에 충전기 추가 시 보통 **2단계 진입** → 평균 단가 **약 200~230원/kWh**
- 7~8월 누진구간 완화 (1단계 300kWh, 2단계 450kWh)
- 별도 계량기 없으면 가정 전체 사용량과 합산되어 누진 적용

### 3. 공공 완속 충전 (환경부/한국환경공단)
- 환경부 공공 완속 (7~14kW): **약 324.4원/kWh**
- 충전 시간: 80% 충전까지 약 4~6시간 (62kWh 배터리 기준)
- 위치: 아파트·관공서·대형마트 주차장
- 회원·비회원 동일

### 4. 공공 급속 충전 (환경부 100kW급)
- 환경부 공공 급속 (100kW 이상): **약 347.2원/kWh**
- 충전 시간: 80% 충전까지 약 30~40분
- 위치: 고속도로 휴게소·환경공단 운영 거점
- 한국환경공단 "환경부 충전기" 앱·카드 사용

### 5. 민간 급속 충전 (회원/비회원 단가 다름)
- GS차지비: 회원 335원/kWh, **비회원 470원/kWh**
- 에버온: 회원 324.4원/kWh, 비회원 약 380원/kWh
- SK일렉링크: 구독제 월 19,900원 + 295원/kWh (구독자 한정)
- 차지비/티맵EV/소프트베리: 350~450원/kWh

## 5년 충전비 시뮬레이션 (전비 5.5km/kWh, 연 1만 5천km, 7만 5천km 누적)

- 동급 가솔린 중형: 연 약 213만원 → **5년 약 1,063만원**

- 공공 완속: 약 621만원 절감

## 하이브리드 충전 패턴 (현실 시뮬레이션)

대부분의 전기차 운전자는 단일 충전 방식만 쓰지 않습니다. 평균 패턴:
- 일상 출퇴근 70%: 가정 충전 (심야 또는 일반)
- 주말 장거리 20%: 공공 완속·급속
- 출장·여행 10%: 민간 급속 (회원·비회원 혼합)

**현실 가중평균 단가 예시:**
- 아파트 입주민(가정 충전기 보유): 70%×70원 + 20%×347원 + 10%×400원 = 약 158원/kWh → 연 약 43만원
- 아파트 입주민(가정 충전기 없음): 70%×324원 + 20%×347원 + 10%×400원 = 약 336원/kWh → 연 약 92만원
- 빌라/단독(전용 충전기): 70%×70원 + 20%×347원 + 10%×400원 = 약 158원/kWh → 연 약 43만원

## 손익분기·시나리오

### 가장 절감 효과 큰 경우
1. 아파트·단독 가정 충전기 보유 + 심야 충전: 5년 약 968만원 절감 (가솔린 대비)
2. 연 2만km 이상 장거리 운전자 (절감 폭 비례 확대)

### 절감 효과 작은 경우
1. 전용 충전기 없이 공공·민간만 사용: 5년 422~620만원 절감 (충전기 설치비 회수도 어려움)
2. 연 5,000km 이하 단거리 운전자: 절대 절감액 작음, 가솔린 TCO 유사

### 충전 기반시설 의사결정
- 가정 충전기 설치비 (100~150만원) ÷ 연 절감액 35만원 = **약 3~4년 회수**
- 보조금 활용 시 (지자체별 30~50만원) 회수 기간 2~3년
