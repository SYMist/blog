## 핵심 프로그램 요약

### 1. 희망리턴패키지 — 재기사업화(재창업) [소상공인시장진흥공단]

| 항목 | 내용 |
|------|------|
| 운영 기관 | 소상공인시장진흥공단 (semas.or.kr) |
| 신청 경로 | 소상공인24 (sbiz24.kr) |
| 대상 | 폐업(예정) 소상공인 |
| 지원 유형 | 재창업형(폐업 후 사업자 없는 자) / 업종전환형 / 창업도약형(재창업 1년 미만) |
| 사업화 자금 | 최대 2,000만원 |
| 점포 철거비 | 최대 600만원 |
| 합계 최대 | 2,600만원 |
| 자부담 조건 | 총사업비의 50% (자부담의 70%는 현물 인정: 인건비·임차료 등) |
| 2026년 1차 모집 | 2026년 1월 30일 ~ 2월 27일 (추가모집 수시 공고) |
| 문의 | 소상공인통합콜센터 ☎1533-0100 / 중소기업통합콜센터 ☎1357 |

**자부담 실제 현금 부담 계산**
- 총사업비 4,000만원 기준: 정부 2,000만원 + 본인 2,000만원
- 본인 2,000만원 중 70% = 1,400만원 현물(임차료·인건비) 인정
- 실제 현금 자부담 약 600만원 수준

### 2. 희망리턴패키지 — 특화취업지원 [소상공인시장진흥공단]

| 항목 | 내용 |
|------|------|
| 대상 | 취업 의사 있는 폐업(예정) 소상공인 (만 15세~만 69세) |

| 기초교육 | e러닝 방식, 10시간 이상 (20개 과정 중 5개 이상 수강 필수) |

| 국민취업지원제도 연계 | 구직급여·취업지원서비스 연결 |

| 합계 최대 | 약 135만원 (수당 100만원 + 참여수당 35만원) |

## 신청 흐름 (전체 4단계)

1. **방향 결정**: 재창업 or 취업 전환 선택
2. **희망리턴패키지 등록**: sbiz24.kr에서 온라인 신청 + 서류 제출
3. **교육·컨설팅 이수**: 자금형은 재창업 교육 10h 이수
4. **자금 연계 신청**: 재도전특별자금(중진공) 또는 재창업자금 별도 신청

---

## 서류

### 기본 서류
- 폐업 증명서 (홈택스 발급)
- 신분증 사본
- 통장 사본
- 사업계획서 (재기사업화 신청 시 필수)

### 상황별 추가
- 점포 철거비: 임대차계약서 + 원상복구 견적서
- 재도전특별자금: 재창업 교육 이수 확인서 + 세금 완납 증명서 (홈택스·위택스)
- 사업자등록증 (재창업 후 자금 신청 시)
- 채무조정 성실이행자: 신용회복위원회 성실이행 확인서

## 실측 정보 (정부 안내에 없는 내용)

### 소요 시간
| 단계 | 소요 기간 | 비고 |
|------|---------|------|
| 온라인 신청·접수 | 즉시 | sbiz24.kr |
| 서류 검토·자격 심사 | 2~4주 | 보완 요청 시 추가 소요 |
| 선정 통보 | 심사 후 1~2주 | 불선정 포함 |
| 사업화 협약·착수 | 선정 후 2~3주 | 컨설팅 매칭 |
| 최종 지원금 정산 | 사업 수행 후 | 성과 보고 후 정산 |
| **합계** | **약 2~4개월** | 예산 소진 시 조기 마감 |

### 자주 혼동되는 포인트
- 재기사업화는 보조금이 아닌 "매칭 방식" — 자부담 50% 필요
- 재창업형·업종전환형·창업도약형 유형을 잘못 선택하면 탈락 원인
- 점포 철거비는 임대차 계약 해지 전 신청 필요 (폐업 완료 후 신청 시 불가)
- 기초교육(e러닝) 미완료 시 심화교육·전직장려수당 신청 불가

### 탈락 사유 TOP 5
1. 세금 체납 / 금융기관 연체 이력
2. 자부담 50% 조달 계획 불명확
3. 사업계획서 미흡 (폐업 원인 분석 없음)
4. 유형 오기재 (재창업형·업종전환형·창업도약형 혼동)
5. 재도전특별자금 교육 이수 미완료
