# 리서치: 전라·경남 소상공인 지원금 지역별 총정리 (2026)
slug: jeonla_gyeongnam_smes_2026
작성일: 2026-05-17

---

## 개요
전라북도·전라남도·경상남도 소상공인 지원금(육성자금·이차보전·정책자금)을 지역별로 정리.
각 지역 신용보증재단을 통한 융자·이차보전 중심으로 정리.

---

## 핵심 사실

### 1. 전라남도 (전남) 소상공인 지원금 2026
| 구분 | 사업명 | 한도 | 금리/보전 | 신청처 |
|-----|-------|-----|---------|------|
| 전남도 차원 | 소상공인 육성자금 | 최대 2,000만원 | 이차보전 연 1.5% | 전남신용보증재단 (1588-3884) |
| 여수시 | 시군 이차보전 | 최대 5,000만원 | 연 4% × 2년 | 해당 시군청/전남신보 지점 |
| 목포시 | 시군 이차보전 | 최대 3,000만원 | 연 3% × 2년 | 해당 시군청/전남신보 지점 |
| 광양시 | 시군 이차보전 | 최대 3,000만원 | 연 4% × 2년 | 해당 시군청/전남신보 지점 |
| 구례군 | 시군 이차보전 | 최대 5,000만원 | 최대 3년 | 해당 시군청/전남신보 지점 |
| 기타 18개 시군 | 시군별 상이 | 시군 공고 확인 | 시군 공고 확인 | 해당 시군청 |

- 총 지원 규모: 전남도 + 22개 시군 합산 1,000억원 이상
- 신청 자격: 해당 지역 사업자등록 3개월 이상 영업 중, 도소매·음식·서비스업 상시근로자 5인 미만
- 도 육성자금과 시군 이차보전은 별개 사업 — 같은 대출에 중복 수혜 불가
- 주의: 각 시군 예산 소진 시 조기 마감 — 공고 즉시 신청 권장

### 2. 전라북도 (전북) 소상공인 지원금 2026
- 전북소상공인광역지원센터 (jbsos.or.kr) 운영 — 민생솔루션, 온라인판로, 폐업지원 등 다수 사업
- 일반 소상공인 정책자금: 연 3~4%대 (국가 SEMAS 기준), 최대 7,000만원 (공고별 상이)
- 지역별 특별자금은 전북신용보증재단 또는 전북소상공인광역지원센터 통해 신청
- 전북 내 시군별 이차보전 사업도 존재 — 해당 시군 공고 확인 필수
- 상세 한도·금리: 공고 시점에 변동 가능 → 전북소상공인광역지원센터 또는 기업마당(bizinfo.go.kr)에서 지역명 검색

### 3. 경상남도 (경남) 소상공인 지원금 2026
| 자금 종류 | 한도 | 주요 대상 |
|---------|-----|---------|
| 경영안정자금 | 최대 1억원 | 일반 소상공인 |
| 창업·명절 특별자금 | 공고 확인 | 창업자/명절 전 신청자 |
| 버팀목 특별자금 | 공고 확인 | 경영 위기 소상공인 |
| 희망두드림 특별자금 | 공고 확인 | 업종별 지정 대상 |
| 기업가형 소상공인 특별자금 | 공고 확인 | 성장 의지 있는 소상공인 |
| 청년창업 특별자금 | 공고 확인 | 만 39세 이하 청년 |
| 긴급경영안정자금 (신설) | 최대 1,000만원 | 긴급 경영 위기 |

- 신청처: 경남신용보증재단 (1644-2900)
- 온라인: 보증드림앱 (사업자등록 6개월 초과 개인사업자 비대면 신청 가능)
- 방문: 사업자등록 6개월 이하 → 경남신보 지점 방문 필수
- 지원 대상: 경남 도내 소상공인기본법 제2조 요건 충족자

### 4. 공통 지원 사항 (전국)
- 소상공인 정책자금 (SEMAS): 연 3.36~3.56%, 최대 7,000만원 — 지역 지원과 별개로 신청 가능
- 비수도권 소상공인(전북·전남·경남 모두 해당): 0.2%p 추가 금리 우대

### 5. 실측 소요기간
| 단계 | 소요 일수 | 비고 |
|-----|---------|-----|
| 공고 확인·서류 준비 | 1~5일 | bizinfo.go.kr 지역 공고 검색 |
| 신청서 작성·상담 예약 | 1~3일 | 방문 또는 온라인 예약 |
| 서류 검토·보증 심사 | 7~14일 | 신용보증재단 기준 |
| 대출 실행 | 3~7일 | 보증서 발급 후 협약 은행 |
| **합계** | **약 2~4주** | 서류 완비 기준 |

### 6. 혼동포인트
- 도 육성자금(전남)과 시군 이차보전은 별개 사업. 같은 대출에 두 이차보전 동시 수혜 불가.
- 전남 22개 시군의 마감일·예산·금리 모두 상이 → 해당 시군 공고 직접 확인 필수
- 경남 긴급경영안정자금은 2026년부터 한도가 최대 1억원 → 1,000만원으로 하향 조정됨

### 7. 탈락사유 TOP5
1. 지역 요건 미충족 (사업장 소재지가 해당 시도 밖)
2. 업종 제외 (유흥업소, 사행성 업종)
3. 기존 보증 한도 초과 (신용보증재단 잔여 보증 한도 부족)
4. 사업자등록 기간 미충족 (전남 도 육성자금: 3개월 이상)
5. 연체·금융 불량 이력
