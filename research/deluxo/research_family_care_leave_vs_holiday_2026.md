# 리서치: 가족돌봄휴직 vs 가족돌봄휴가 차이·중복·사용일수 완전 정리 (2026)

## 개요
- 슬러그: family_care_leave_vs_holiday_2026

## 핵심 사실 (2026년 기준)

### 제도 비교표

| 구분 | 가족돌봄휴직 | 가족돌봄휴가 |
|------|------------|-----------|
| 근거 | 남녀고용평등법 제22조의2 | 남녀고용평등법 제22조의3 |
| 돌봄 사유 | 질병·사고·노령 | 질병·사고·노령 + **자녀 양육** (추가) |
| 돌봄 대상 | 조부모·부모·배우자·배우자부모·자녀·손자녀 | 동일 (조부모·손자녀는 조건 있음) |
| 사용 기간 | **연간 최장 90일** (1회 최소 30일 이상, 분할 가능) | **연간 최장 10일** (일단위 분할, 감염병 재난 시 최대 15일) |
| 급여 | **무급** (사업주 지급 의무 없음) | **무급** (일부 지자체 지원금 별도) |
| 중복 관계 | — | 휴가 10일은 휴직 90일 한도에 **포함** |
| 신청 기한 | 개시 30일 전 서면 신청 | 사용 전 서면 신청 (긴급 상황 시 즉시 가능) |
| 조건 | 근속 6개월 이상 | 근속 요건 없음 |

### 가족돌봄휴직 세부 정보

**신청 요건 (모두 충족 시)**:
- 근속기간 6개월 이상 근로자
- 돌봄 대상 가족 해당 사유 (질병·사고·노령)
- 개시 30일 전 서면 제출 (성명·생년월일·돌봄사유·휴직기간·신청일 기재)

**사업주 거부 가능 사유 (예외)**:
1. 근속기간 6개월 미만 근로자
2. 다른 가족이 충분히 돌볼 수 있는 경우
3. 대체인력 채용이 불가능한 경우
4. 사업 운영에 중대한 지장을 초래하는 경우

**기간 계산**:
- 연간 최장 90일 (가족돌봄휴가 사용일 포함)
- 1회 최소 30일 이상 사용 필수 (단기 분할은 15일 단위도 가능한지는 취업규칙 확인)
- 분할 사용 횟수 제한 없음

**법적 보호**:
- 사업주는 휴직 중 해고 불가
- 휴직 기간은 근속기간에 포함 (승진·승급·퇴직금·연차휴가 산정)
- 단, 평균임금 산정 시에는 제외

### 가족돌봄휴가 세부 정보

**신청 요건**:
- 사용 목적: 질병·사고·노령 또는 자녀 양육으로 긴급 돌봄 필요
- 서면 또는 전자문서로 사업주에게 제출 (사전 신청 원칙)
- 근속기간 요건 없음

**조부모·손자녀 돌봄 제한**:
- 다른 직계비속·직계존속이 있으면 원칙적으로 허용 불가
- 단, 다른 가족에게 질병·노령·장애·미성년 등 사유 있으면 예외

**사업주 위반 시**:
- 휴가 허용 거부 시 500만원 이하 과태료
- 부당 해고·근로조건 악화 시 3년 이하 징역 또는 3천만원 이하 벌금

---

### 중복 사용 관계 — 핵심!

**가족돌봄휴가 10일 = 가족돌봄휴직 90일 한도에 포함**

예시:
- 가족돌봄휴가 10일 사용 → 남은 가족돌봄휴직 가능 기간 80일
- 가족돌봄휴가 0일 사용 → 가족돌봄휴직 최대 90일 사용 가능
- 가족돌봄휴직 60일 + 가족돌봄휴가 10일 = 총 70일 사용 (나머지 20일 추가 가능)
- **단, 연간 총 합계는 90일을 초과할 수 없음**

### 절차별 소요 시간

| 단계 | 소요 기간 | 비고 |
|------|----------|------|
| 가족돌봄휴직 서면 신청 | 개시 30일 전 | 서식 없음, 자유 서면 |
| 사업주 검토·허가 | 약 1~2주 | 거부 사유 없으면 자동 허가 |
| 가족돌봄휴가 신청 | 즉시 (긴급 시) | 사전 서면 원칙, 긴급 시 당일 가능 |
| **가족돌봄휴직 실제 개시** | 신청일로부터 **최소 30일 이후** | 30일 전 신청 의무 |

---

### 자주 혼동되는 포인트

1. **가족돌봄휴가 10일이 별도 추가 아님**: 가장 많이 오해하는 부분. 가족돌봄휴가 10일은 가족돌봄휴직 90일 한도에 포함. 즉, 총 100일 사용이 아닌 90일 한도.
2. **가족돌봄휴직 1회 30일 미만 불가**: 가족돌봄휴직은 한 번에 최소 30일 이상 사용해야 함. 1~2주 단기 사용이 필요하면 가족돌봄휴가(최대 10일)를 사용해야 함.
3. **가족돌봄휴직 사유**: 질병·사고·노령만 해당. 자녀 양육은 해당 안됨 (자녀 양육은 가족돌봄휴가만 가능, 또는 육아휴직).
4. **가족돌봄휴가도 무급**: 유급이라고 오해하는 경우 있음. 두 제도 모두 무급.
5. **근속 6개월 요건**: 가족돌봄휴직만 해당, 가족돌봄휴가는 근속 요건 없음.
