# 리서치: 가족법인 설립 절차·비용·절세 효과 완전 정리 (2026)
slug: family_corp_setup_guide_2026
작성일: 2026-05-18

---

## 개요
가족 구성원(부모·자녀 등)만으로 구성하는 법인 설립 절차·비용·절세 효과 정리.
주식회사 형태 기준. 소규모 가족법인(자본금 10억 미만) 중심.

---

## 핵심 사실

### 1. 가족법인이란?
- 가족 구성원만이 주주와 임원으로 참여하는 법인
- 법적으로 별도 제도가 있는 것이 아니라, 일반 주식회사·유한회사를 가족으로 구성한 것
- 이사 2명 이하 권장 (3명 이상 시 이사회 의사결정 절차 복잡해짐)
- 감사: 자본금 10억 미만 시 선임 불필수
- 최소 자본금: 법적 하한선 없으나 실무상 100만원 이상 (1,000만원 이상 권장)
- 미성년자: 주주로 참여 가능 / 임원은 만 16세 이상 가능
- 직장인: 주주는 가능, 임원은 겸직금지의무 고용계약 확인 필수
- 공무원: 발기인 불가, 기존 법인 주식 양수만 가능

### 2. 설립 비용 (2026년 기준)

#### 비과밀억제권역 (지방, 경기 일부)
| 항목 | 자본금 2,800만원 이하 | 자본금 1억원 기준 |
|-----|------------------|----------------|
| 등록면허세 | 112,500원 | 400,000원 |
| 지방교육세 | 22,500원 | 80,000원 |
| 등기신청수수료 | 20,000원 | 20,000원 |
| 공과금 합계 | 약 155,000원 | 약 500,000원 |

#### 과밀억제권역 (서울 등 수도권)
- 등록면허세 **3배 중과**: 337,500원 (자본금 2,800만원 이하 기준)
- 지방교육세: 67,500원
- 등기신청수수료: 20,000원
- 공과금 합계: 약 **42.5만원** (자본금 2,800만원 이하 기준)

#### 법무사·변호사 대행 시 추가 비용
- 수수료: 15~50만원 (업체별 상이, 자본금 규모에 따라 증가)
- 법인 인감 제작: 3~5만원

#### 총 설립비용 범위
| 방식 | 비과밀권역 | 과밀억제권역 |
|-----|---------|------------|
| 셀프 등기 | 약 15~20만원 | 약 43~50만원 |
| 법무사 대행 | 약 30~70만원 | 약 60~100만원+ |

### 3. 법인세율 vs 소득세율 (2026년 기준)

#### 법인세율 (국세청 고시, 2026.1.1. 이후 개시 사업연도 적용)
| 과세표준 | 세율 | 누진공제 |
|---------|------|---------|
| 2억원 이하 | 10% | - |
| 2억~200억원 이하 | 20% | 2,000만원 |
| 200억~3,000억원 이하 | 22% | 4억2,000만원 |
| 3,000억원 초과 | 25% | 9억4,200만원 |

#### 개인사업자 소득세율
| 과세표준 | 세율 |
|---------|------|
| 1,200만원 이하 | 6% |
| 1,200만~4,600만원 | 15% |
| 4,600만~8,800만원 | 24% |
| 8,800만~1억5,000만원 | 35% |
| 1억5,000만~3억원 | 38% |
| 3억~5억원 | 40% |
| 5억~10억원 | 42% |
| 10억원 초과 | 45% |

### 4. 절세 효과 시뮬레이션

#### 순이익 1억원 기준 비교
- **개인사업자**: 소득세 약 2,010만원 + 지방소득세 201만원 = 약 **2,211만원**
  (35% 구간, 누진공제 1,490만원)
- **법인 (대표이사 급여 4,000만원 설정 시)**:
  - 법인 과세표준: 1억 - 4,000만 = 6,000만원 → 법인세 600만원
  - 대표이사 급여 소득세: 4,000만원 기준 약 330만원(지방소득세 포함)
  - 합계: **약 930만원**
  - **절감액: 약 1,281만원/년**

#### 절세 손익분기점 (일반 기준)
- 순이익 **5,000만원 이상**, 총매출 **6~10억원 이상**이 되면 법인 전환 효과가 의미 있음
- 소규모(순이익 1,000만원 미만): 법인 유지 비용(세무기장료·4대보험 등)이 절세액보다 클 수 있음

### 5. 설립 절차 (6단계)
1. 상호 사전 확인 — 인터넷 등기소(iros.go.kr)에서 동일·유사 상호 검색
2. 정관 작성 — 전문가 작성 강력 권장 (출처 불명 무료 정관 사용 금지)
3. 자본금 납입 — 발기인 통장에 입금 후 잔액증명서 발급
4. 법인 설립 등기 신청 — 인터넷 등기소 전자신청 또는 법무사 대행
5. 사업자등록 신청 — 세무서 방문 또는 홈택스(hometax.go.kr) 온라인
6. 법인 통장 개설 + 4대보험 사업장 성립 신고

### 6. 실측 소요기간
| 단계 | 소요 일수 | 비고 |
|-----|---------|-----|
| 서류 준비·상호 확인 | 1~3일 | 정관 전문가 의뢰 시 1~3일 추가 |
| 자본금 납입·잔액증명 | 당일~1일 | 은행 방문 기준 |
| 법인 설립 등기 | 3~5일 | 전자신청 기준, 법무사 대행 동일 |
| 사업자등록 | 3~7일 | 홈택스 즉시 접수, 처리 3~7일 |
| 법인 통장 개설 | 1~3일 | 설립 서류 지참 방문 |
| **합계** | **약 2~4주** | 서류 완비 기준 |

### 7. 주요 주의사항 / 탈락 포인트
1. 실질적 사업 운영 없이 절세 목적만으로 형식 운영 시 세무조사 대상
2. 가족 간 거래는 반드시 시가 기준 — 저가 양수도 시 증여세·법인세 추징
3. 과밀억제권역 설립 시 등록면허세 3배 중과
4. 대표이사 급여 과다 설정 시 '부당행위계산 부인' 위험
5. 법인 자금을 사적으로 사용하면 가지급금 처리 → 인정이자 과세 + 가산세

### 8. 절세 수단 정리
| 방법 | 절세 원리 | 주의사항 |
|-----|---------|---------|
| 대표이사 급여 설정 | 법인 비용 인정, 과세표준 감소 | 시장 수준 초과 시 부인 위험 |
| 가족 임원 급여 | 실제 근무 기반 비용 처리 | 허위 급여는 탈루로 처리 |
| 퇴직금 적립 | 법인 비용 인정 | 임원 퇴직금 지급 규정 정관에 명시 필요 |
| 법인 차량 운용 | 업무용 차량 비용 처리 | 업무 사용 비율 입증 필요 |
| 자녀 주주 배당 | 소득 분산, 종합소득세 절감 | 실제 지분에 따른 배당 |
