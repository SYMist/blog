## 1. 노란우산공제

### 소득구간별 소득공제 한도 (2026년 기준)
| 사업소득 구간 | 공제 한도 | 비고 |
|------------|---------|------|
| 4,000만원 이하 | **600만원** | 2025년부터 500만원→600만원 상향 |
| 4,000만원 초과~1억원 이하 | **400만원** | |
| 1억원 초과 | **200만원** | |

- 공제 방식: **소득공제** (종합소득세 과세표준 직접 감소)
- 납입 월한도: 월 100만원 (연 1,200만원) — 공제 한도 초과분은 공제 불가
- 복리 이율: 연 3~4% 수준 (2026년 기준)
- 중소기업중앙회 관리, 원금·이자 압류 금지 혜택
- 신청처: 노란우산공제 (yumam.kbiz.or.kr) 또는 소상공인시장진흥공단

### 절세 효과 (소득 4,000만원 이하, 세율 15%)
- 600만원 납입 → 과세표준 600만원 감소 → 소득세 약 **90만원** 절감

## 2. IRP (개인형 퇴직연금) + 연금저축

### 세액공제 한도 (2026년 기준)
| 구분 | 공제 한도 | 공제율 (종합소득 4,500만원↓) | 공제율 (초과) |
|------|---------|--------------------------|------------|
| 연금저축 | 연 600만원 | 16.5% | 13.2% |
| IRP (단독) | 연 900만원 | 16.5% | 13.2% |
| 연금저축+IRP 합산 | **연 900만원** | 16.5% | 13.2% |

### 최적 납입 전략
- **연금저축 600만원 + IRP 300만원** = 합산 900만원 → 세액공제 최대
  - 종합소득 4,500만원 이하: 900만원 × 16.5% = **148.5만원** 절세
  - 종합소득 4,500만원 초과: 900만원 × 13.2% = **118.8만원** 절세
- IRP 단독 900만원 납입도 가능 (연금저축 없이)
- 주의: IRP 중도인출 시 기타소득세 16.5% 추징

### 신청처
- 시중은행, 증권사 IRP 계좌 개설 (온라인 가능)

## 3. 국민연금 (자영업자 지역가입자)

### 2026년 개혁 변화
- 보험료율: 9% → **9.5%** (2026년), 이후 매년 0.5%p↑, 2033년 13% 목표
- 소득대체율: 기존 40% → **43%** 상향
- 납부 보험료 범위: 월 38,000원~605,150원

### 자영업자 국민연금 특이점
- 자영업자 = **지역가입자** 자동 분류 (직장인과 달리 사업주 분담 없음 → 전액 본인 부담)
- 소득 신고 방식: 종소세 신고 기준 소득 → 다음 해 6월부터 보험료 재산정
- 소득 줄면 **보험료 감액 신청** 가능 (소득 감소 신고)

### 임의가입 (배우자·전업 자영업자 무소득 기간 등)
- 대상: 18~60세 미만 중 의무가입 대상이 아닌 자 (배우자, 전업주부 등)
- 신청: 국민연금공단 온라인 또는 지사 방문 / ☎1355
- 최저 보험료: 월 38,000원부터 선택 가능
- 효과: 가입기간 늘려 노령연금 증가

### 임의계속가입
- 대상: 60세 이후 가입기간 부족 시 65세까지 연장 가능
- 효과: 10년 이상 납입 충족 시 종신 연금 수령 자격 확보

## 4. 3축 통합 절세 시뮬레이션

### 자영업자 종합소득 4,500만원 이하 기준
| 항목 | 납입액 | 절세 효과 |
|------|------|---------|
| 노란우산공제 | 600만원 | ~90만원 (소득공제, 세율 15%) |
| 연금저축 | 600만원 | ~99만원 (세액공제 16.5%) |
| IRP | 300만원 | ~49.5만원 (세액공제 16.5%) |
| **합계** | **1,500만원** | **약 238만원** 절세 |

### 소득 4,500만원 초과 ~ 1억원 이하 기준
| 항목 | 납입액 | 절세 효과 |
|------|------|---------|
| 노란우산공제 | 400만원 | ~100만원 (세율 24~35%) |
| 연금저축+IRP | 900만원 | ~118.8만원 (세액공제 13.2%) |
| **합계** | **1,300만원** | **약 220만원** 절세 |

## 5. 탈락/손실 사례 TOP5

1. 노란우산 납입 후 종소세 신고 시 공제 신청 누락 (자동 미적용)
2. 국민연금 소득 줄었는데 감액 신청 안 해 보험료 과다 납부 지속
3. IRP 중도인출로 기타소득세 16.5% 추징 (60세 이전 해지 = 연금 혜택 상실)
4. 연금저축과 IRP 한도 혼동 — "IRP만 900만원 가능"을 모르고 연금저축만 600만원 납입
5. 노란우산 해지 시 해지소득세(퇴직소득세) 별도 발생 — 중도 해지 비용 과소 인식
