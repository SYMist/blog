# essencial_guidelines.md
# essencial 블로그 비교형 콘텐츠 가이드라인 v1.0 (2026-03-22)

## 1) 적용 범위
- 블로그: essencial (티스토리)
- 글 유형: 비교·의사결정형 (A vs B, 비용 계산, 조건별 추천)
- 대표 검색 의도: **뭐가 유리한지 → 비용 차이 → 조건 비교 → 신청/가입 방법 → FAQ**
- 타겟 독자: 40~60대 (실용 정보 검색자)
- 주요 유입 채널: 구글, 네이버 (다음 X — 저품질 처리 상태)

---

## 2) 핵심 원칙

### A. 비교형 콘텐츠의 본질
- 독자는 "뭘 골라야 하나"를 알고 싶어서 왔다 → **결론(추천)을 먼저** 제시
- 정보 나열이 아니라 **상황별 유불리 판단**을 도와주는 글
- "~가 좋다"가 아니라 **"~한 상황이면 A, ~한 상황이면 B"** 프레이밍

### B. 출처 신뢰
- 공식 사이트/약관/금감원/건보공단 등 **공신력 있는 출처** 기반
- 보험료·금리·비용 수치는 **기준 시점 명시** (예: 2026년 3월 기준)
- 본문 모든 링크는 **접속 가능 여부 확인** 후 삽입

### C. 키워드 전략 — 롱테일 + 비교형 Only
- 헤드 키워드(2~3단어) 진입 금지 (예: "자동차보험 비교" ✕)
- **5~7단어 롱테일** + 비교/의사결정 프레이밍 (예: "50대 실비보험 갈아타기 체크리스트" ✓)
- 연령·상황·조건을 키워드에 포함하여 경쟁 회피

### D. 글자 수 / 가독성
- **2,000~3,000자** 권장 (구글 SEO에 유리한 중장편)
- H2/H3로 계층화, 문단 3~4줄, 비교표 필수
- 상단 15초 안에 결론 도달

### E. H3 소제목은 질문형 권장
- 상세 비교 섹션의 H3는 **질문형**으로 작성 → 구글 PAA(People Also Ask) 노출 확률 증가
- 예: `보장 범위는 어떻게 다를까?`, `갱신 시 보험료는 얼마나 오를까?`, `중도상환 수수료는 면제 가능할까?`
- 질문형이 어색한 항목은 서술형 허용하되, 전체의 **60% 이상은 질문형** 유지

### F. 단정 금지
- "무조건 이게 좋다" 금지 → **"~한 경우에는 A가 유리하다"**
- 보험·금융 콘텐츠는 특히 **면책 문구 필수**: "개인 상황에 따라 다를 수 있으며, 가입 전 약관 확인 필요"

## 3) Silo별 콘텐츠 유형

### Silo 1: 건강·의료 (essencial_template_health.html)
- 패턴: 비용 + 보험적용 여부 + 어디서 받나
- 필수 요소: 비용 비교표, 건강보험/실비 적용 조건, 병원 찾기 CTA
- 예: "임플란트 건강보험 적용 조건 본인부담금 계산"

### Silo 2: 자동차 (essencial_template_auto.html)
- 패턴: 절세 + 행정절차 + 비용 비교
- 필수 요소: 단계별 절차, 비용 시뮬레이션표, 필요 서류
- 예: "중고차 이전등록 셀프 비용 vs 대행 비교"

### Silo 3: 보험 비교 (essencial_template_insurance.html)
- 패턴: A vs B 조건별 유불리
- 필수 요소: 조건별 비교 매트릭스, 시나리오별 추천, 주의사항
- 예: "암보험 갱신형 vs 비갱신형 60세 이후 보험료 차이"

### Silo 4: 대출·금융 (essencial_template_finance.html)
- 패턴: 자격요건 + 금리/한도 + 상품 비교
- 필수 요소: 자격 자가진단, 상품 비교표, 신청 프로세스
- 예: "소액 생활자금 대출 카카오뱅크 vs 토스뱅크 vs 케이뱅크"

## 4) 본문 구조 (비교형 공통 흐름)
1) **결론 먼저**: 상황별 추천 3줄 요약
2) **비교표**: 핵심 항목 비교 매트릭스 (Silo별 템플릿 참조)
3) **상세 비교**: 항목별 깊이 있는 분석
4) **시나리오 추천**: "당신이 ~라면 → A / ~라면 → B"
5) **주의사항/함정**: 놓치기 쉬운 포인트
6) **FAQ 6~10개**
7) **업데이트 로그**

## 5) 제목 작성 요령

### A. 비교형 제목 공식 (6개)
1) `{A} vs {B} {조건} 비교: {연령/상황}이면 뭐가 유리? ({연도})`
2) `{키워드} 비용 총정리: {항목별} 실제 부담금 계산 ({연도})`
3) `{키워드} {연령}대 추천: 상황별 선택 가이드`
4) `{키워드} 갈아타기 전 꼭 확인할 {N}가지 ({연도})`
5) `{키워드} 신청방법 {셀프 vs 대행} 비용 차이`
6) `{키워드} 장단점 비교: {상황A}면 A, {상황B}면 B`

### B. 제목 규칙
- **비교 대상을 제목에 명시** (A vs B, A와 B 차이)
- **연령/상황 키워드 포함**으로 롱테일 확보
- **30자 이내** 권장
- 숫자·연도 활용
- 과장 표현 금지 ("최저", "무조건", "반드시" 등)

## 6) SEO — 구글/네이버 최적화 (다음 X)

### A. 구글 SEO (최우선)
- **meta description**: 150자 이내, 비교 결론 포함 (티스토리 설정 > 기본설정 > 설명)
- **H2/H3 계층 구조**: 비교 항목을 H3로 분리
- **E-E-A-T 신호**: 기준 시점 명시, 출처 링크, 업데이트 로그
- **Schema.org**: BlogPosting + FAQPage (템플릿에 포함)
- **본문 길이**: 2,000자 이상 권장
- **내부링크**: 같은 Silo 내 글끼리 상호 링크

### B. 네이버 SEO
- **네이버 서치어드바이저** 등록 필수
- **제목 키워드 매칭**: 네이버는 제목 일치도를 중시
- **최신성**: 발행일/수정일이 최근일수록 유리
- **이미지 ALT 텍스트**: 네이버 이미지 검색 유입 가능

### C. 다음(Daum) — 비적용
- essencial 블로그는 다음 저품질 상태이므로 다음 SEO는 고려하지 않음
- 이미지 개수 최적화(다음 가중치)도 불필요

## 9) 태그 구성

### A. 태그 개수: 10~15개

### B. 태그 구성 공식
1) **핵심키워드 3개**: 메인키워드 / A vs B / 비교 관련 변형
2) **행동/의도 3개**: 비교 / 추천 / 선택 가이드
3) **타겟 2~3개**: 연령대 / 상황 / 직업
4) **연관 2~3개**: Silo 내 연관 주제
5) **연도 1개**: 2026비교 / 2026추천

### C. 태그 출력 규칙
- 태그는 HTML 본문에 삽입하지 **않는다** (티스토리 에디터에서 별도 입력)
- **블로그 글 작성 완료 후**, 채팅창에 아래 형식으로 태그를 출력한다:

```
**태그 (N개)**
태그1, 태그2, 태그3, ...

| 구분 | 태그 |
|------|------|
| 핵심 키워드 (3) | ... |
| 행동/의도 (3) | ... |
| 타겟 (2~3) | ... |
| 연관 (2~3) | ... |
| 연도 (1) | ... |
```

## 10) 광고 배치

- 자동광고: 티스토리 스킨 편집의 pub 코드로 전 페이지 자동 노출

### B. 인아티클 코드 위치 (Silo별 동일)
- **시나리오 추천 박스 직후** — `<div class="scenario">…</div>` 종료 직후 + 시나리오 카드 이미지 위에 삽입
- 슬롯 ID: `2039167138` (essencial 전용 인아티클 단위)
- 4개 Silo 템플릿(health/auto/insurance/finance)에 동일 코드 박혀 있음 — 새 글은 그대로 복붙

### C. 광고 정책 위반 회피
- 같은 페이지에 인아티클 단위를 **2개 이상 중복 삽입 금지**

## 11) DO & DON'T

### ✅ DO
1. **결론 먼저** — 상단 3줄에 상황별 추천 결론
2. **비교표 필수** — 텍스트만으로 비교하지 말고 반드시 표 포함
3. **시나리오 프레이밍** — "당신이 ~라면" 형태로 개인화
4. **기준 시점 명시** — 모든 금액/금리/보험료에 기준일 표기
5. **면책 문구** — 보험·금융 글 하단에 면책 문구 필수
6. **보험사·금융사 공식 사이트와 차별화하는 5가지** (콘텐츠 권위 가속) — 보험사·은행 공식 사이트는 자사 상품 정보만 있다. AI 초안 정보만으로는 색인·ranking 진입이 어렵다. 글마다 아래 중 최소 **2~3개**를 명시 적용:
   1) **A vs B 직접 비교 매트릭스** — 같은 표에서 두 상품 한눈에 (공식은 자기 상품만)
   2) **상황별 추천 시나리오** — "당신이 ~라면 A, ~라면 B" (공식은 자사 추천만)
   3) **숨겨진 비용·함정** — 약관에 작게 적힌 조항, 중도해지 페널티, 갱신 시 인상폭 등 (공식은 강조 안 함)
   4) **갈아타기 ROI 계산** — 환급금 vs 새 상품 절약 비용 시뮬레이션, 손익분기점 시점
   5) **자주 놓치는 포인트와 실수 사례** — 가입자들이 자주 헷갈리는 항목, 약관 검토 시 흔히 간과되는 조항, 상담사가 자주 안내하는 디테일

### 작성자 / 톤
- **차별화 5가지는 Claude가 작성**한다 (사용자가 키워드 요청 시 함께 채움). 톤은 객관 정보 또는 3인칭 일반화 — "가입자들이 자주 ~", "약관 검토 시 흔히 간과되는 ~", "상담사들이 자주 안내하는 ~" 형태.
- **fabricated 1인칭 경험은 작성 금지** ("내가 가입해보니 ~" 같은 톤). Google E-E-A-T가 점점 강해져 거짓 경험은 역효과.
- 사용자가 진짜 경험을 가진 글에만 1인칭으로 추가·수정 가능. 그 경우 H2 제목을 "본인 경험"으로 바꾸고 사용자가 직접 손봄.

### ❌ DON'T
1. **헤드 키워드 진입 금지** — "자동차보험 비교" 같은 2~3단어 키워드로 쓰지 않음
2. **일방적 추천 금지** — "A가 무조건 좋다" 식 단정 표현
3. **다음 SEO 최적화 금지** — 이미지 개수 맞추기 등 다음 가중치 고려 불필요
4. **정책/신청 가이드 형태 금지** — 그건 deluxo 블로그 영역
5. **출처 없는 수치 금지** — 보험료/금리는 반드시 출처와 기준일

- [ ] **시나리오 추천 직후 인아티클 광고 코드(슬롯 `2039167138`)가 그대로 박혀 있는가** — 템플릿에서 복붙되었는지 ctrl+F로 확인
- [ ] 금액/금리/보험료에 기준 시점이 명시되어 있는가
- [ ] 보험·금융 글이면 면책 문구가 있는가
- [ ] 모든 링크가 접속 가능한가
- [ ] **관련 글 영역의 내부링크가 실제 Tistory URL로 채워졌는가** (`href="#"`나 텍스트만 있는 상태 금지)
- [ ] **티스토리 발행 옵션의 메타 description 수동 입력** (150자 이내) — 본문 첫 문단을 그대로 두지 말고 "**검색결과에서 클릭하고 싶은 1~2문장**"으로 가다듬어 입력. CTR 직접 영향
- [ ] **글 첫 문단이 매력적인가** — 결론 + 키워드 + 다음을 보고 싶게 만드는 문장. 메타 description을 안 채우면 이 문단이 그대로 노출됨
- [ ] H2/H3 계층 구조가 올바른가

- [ ] 업데이트 로그에 날짜가 기입되어 있는가
- [ ] 태그 10~15개 (핵심+행동+타겟+연관+연도)

## 13) 운영 타임라인 — 새 글 ranking 진입과 권위 누적

### 새 글 ranking 진입까지 시간
- **발행 직후~1주**: 검색엔진이 페이지 발견·크롤. ranking 노출 거의 없음
- **1~2주**: 평가 시작, 일부 롱테일 키워드에서 노출 시작
- **2~4주**: ranking 안정화 시작. 인기글 진입 가능
- **4주~**: 권위 누적되며 점진적 ranking 상승

→ **새 글이 즉시 트래픽을 가져오지 않는 게 정상**. "옛 글이 1·2위에 잘 뜨고 새 글이 안 떠도" 시간 누적 신호이지 방향성 문제 아님.

### 광고 슬롯 워밍업
- **신규 인아티클 광고 슬롯**: AdSense 알고리즘 학습에 2~4주 필요. 단가 안정화는 그 후.
- 노출 RPM이 낮게 나와도 표본 부족(10건 미만)이면 아직 평가 단계.
- 평균 단가는 **30일 누적**으로 봐야 의미 있음.

### CTR / 게재순위 개선 신호
- 평균 CTR 1.1% 미만 + 게재순위 5~10 → 메타 description 수동 입력으로 개선 시도
- 평균 게재순위 10 초과 → 키워드가 너무 경쟁적이거나 콘텐츠 권위 부족. 롱테일 5~7단어로 재구성 검토
- 인기 검색어가 의도한 Silo 키워드와 다르면 → 장기적으로 새 가이드라인 콘텐츠가 누적되기 기다리거나, 트래픽 상위 옛 글에 인아티클 retrofit 검토

### 운영 점검 주기
- **D+7**: 색인 시작 / 광고 슬롯 첫 노출 확인
- **D+14**: 인기 검색어에 신규 키워드 진입 시작
- **D+30**: ranking 안정화 시작 / 광고 RPM 의미 있는 평가
- **D+90**: 도메인 권위 변화 측정 (특히 신생 자산)
