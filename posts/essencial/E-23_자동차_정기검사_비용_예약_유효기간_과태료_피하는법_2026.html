3) 예약 방법 — TS·네이버·시간대 전략

어디서 예약하나?

채널방법특징
TS 사이버검사소차량번호 + 생년월일 6자리전국 공단·민간 통합 조회, 검사 대상 확인

  • 추천 시간대: 화~목요일 오후 14:00~16:00
  • 공단 예약 마감 시: 주변 민간 검사소 → 당일·즉시 수검 가능

부적합 판정 시 재검사는?

  • 10일 이내 재검사 → 추가 수수료 없음 (해당 항목만 재확인)
  • 10일 초과 → 수수료 재부과 + 유효기간 초과 시 과태료 발생 가능
  • → 부적합 판정 즉시 정비 완료가 핵심

8) 시나리오별 추천

당신의 상황에 맞는 행동은?

  • 만료 3개월+ 남음 + 여유 있음 → TS 공단 예약 (저렴 + 감면 적용)
  • 만료 1개월 이내 + 공단 예약 꽉 참 → 민간 검사소 당일 수검 (추가 2만 원 < 과태료 4만 원)
  • 장애인·다자녀·수급자 → 반드시 TS 공단 직영 (민간은 감면 불가)
  • 디젤 차량 → 검사 전 30분 고속주행 (DPF 재생) + 요소수 확인
  • 전기차 → OTA 업데이트 확인 + 리콜 조치 완료
  • 해외 출장·입원 등 부득이한 사정 → 유효기간 내 유예 신청 (정부24)

지금 바로 확인하는 순서
  1. 검사 대상 확인: TS 사이버검사소에서 차량번호 입력 → 유효기간 조회
  2. 만료일 확인: 90일 전부터 수검 가능 → 달력에 표시
  3. 예약: TS 사이버검사소 or 네이버 → 화~목 오후 추천
  4. 사전 점검: 등화장치 5분 자가 점검 (전조등·방향등·제동등·번호판등)
  5. 수검: 디지털 문진표 미리 작성 → 현장 15분 이내 완료

9) FAQ

Q1. 자동차 정기검사 비용은 얼마인가요?

TS 공단 직영 기준 경차 17,000원, 소형 승용 23,000원, 중형 26,500원, 대형 29,000원입니다. 종합검사는 48,000~65,000원이며, 민간 검사소는 5,000~20,000원 추가됩니다. 장애인·다자녀 가구 등은 공단 직영에서 감면 혜택을 받을 수 있습니다.

Q2. 신차 첫 검사는 언제 받나요?

2025년부터 비사업용 승용차의 최초 검사 유효기간이 4년에서 5년으로 연장되었습니다. 신차 등록 후 5년 뒤 첫 검사를 받고, 이후 매 2년마다 검사합니다.

Q3. 검사를 일찍 받으면 유효기간이 줄어드나요?

아닙니다. 만료일 90일 전부터 검사 가능하며, 조기 수검해도 다음 유효기간 만료일은 변하지 않습니다. 총 122일의 여유가 있으니 일찍 받는 게 유리합니다.

Q4. 과태료는 얼마인가요?

만료 후 30일 이내 4만 원, 31~114일은 4만 원 + 3일마다 2만 원 가산, 115일 이상은 최대 60만 원입니다. 1년 이상 미수검 시 운행정지명령까지 내려질 수 있습니다.

Q5. 검사 예약은 어디서 하나요?

TS 사이버검사소 또는 네이버 예약에서 가능합니다. 2026년부터 완전 예약제이며, 차량번호와 생년월일 6자리로 대상 여부를 즉시 조회할 수 있습니다.

Q6. 부적합 판정 시 재검사 비용이 있나요?

10일 이내 재검사 시 추가 수수료 없이 해당 항목만 재확인합니다. 10일을 넘기면 수수료가 재부과되고, 유효기간 초과 시 과태료가 발생할 수 있으므로 즉시 정비 후 재검사를 받으세요.

Q7. 전기차 검사는 뭐가 다른가요?

2026년부터 BMS 데이터 실시간 추출이 의무화되어 셀 전압 편차, 배터리 수명(SOH), 충방전 이력을 정밀 분석합니다. 리콜 통지 후 1년 6개월 내 미조치 차량은 부적합 판정을 받습니다.
