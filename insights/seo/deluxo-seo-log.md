# deluxo SEO 개선 로그

대상 블로그: `tistory.deluxo.co.kr` (deluxo, 소상공인 정책) → `ricorico.tistory.com`으로 메인 전환 결정 (2026-05-26)
작업 기간: 2026-03 ~ 진행 중
다음 측정: **AdSense ricorico 승인 후 + D+14 (~2026-06 중하순 예상)**

---

## 1. 블로그 인프라 구조

3계층 구조:

| 계층 | 서비스 | 역할 | 비용 |
|---|---|---|---|
| 도메인 | 가비아 | `deluxo.co.kr` 소유권 | 연 ~2.2만원 (갱신 필수) |
| DNS·CDN·SSL | 클라우드플레어 | DNS 관리 + 무료 HTTPS + CDN | 무료 |
| 호스팅 | Tistory | 실제 블로그 콘텐츠 | 무료 |

병행 도메인:
- `ricorico.tistory.com` — Tistory 원본 무료 도메인, alias 유지
- canonical은 deluxo가 메인, ricorico는 alias 상태

핵심 결정:
- 가비아 도메인 갱신 안 하면 모든 작업 무효화 → **연장 필수** (3~5년 일괄 권장)
- ricorico와 deluxo 동시 운영 (소프트 canonical만) → 사실상 B안 상태로 운영 중이라 도메인 통합·301 redirect 불필요

## 2. 초기 진단 (2026-03 ~ 04 초)

### 발견된 SEO 이슈 (6개)
1. robots.txt에 sitemap 미등록 (Tistory에서 직접 수정 불가)
2. 이미지 alt 텍스트 전무
3. FAQ 있으나 JSON-LD 미적용
4. 자체 블로그 내부 링크 0개 (외부 정부 링크만)
5. 비교 표(table) 부재
6. 카테고리 단 2개 (생활경제정보 / 배당주정보)

### 부가 발견
- 일부 URL slug에 em-dash(—), en-dash(–), full-width 파이프(｜), middle-dot(·) 등 특수문자
- canonical·og 태그가 정적 HTML에 없음 (Tistory 동적 처리)

## 3. 작업 내역 (2026-04-25)

| # | 작업 | 효과 가설 |
|---|---|---|
| 1 | 블로그 description 교체 (저품질 generic 키워드 제거 → 실제 토픽) | 사이트 단위 신호 개선 |
| 2 | GSC URL 검사로 핵심 글 5편 색인 요청 | 색인 가속 |
| 3 | 네이버 서치어드바이저 deluxo 자산 신규 등록 + HTML 메타 태그 verification | 네이버 채널 열림 |
| 4 | 네이버 사이트맵(`sitemap.xml`) + RSS(`rss`) 제출 | 네이버 색인 시작 |
| 5 | 네이버 웹페이지 수집 요청 5편 | 네이버 색인 가속 |

### head 메타 태그 최종 구조
```html
<meta name="naver-site-verification" content="887e..." />  <!-- ricorico용 -->
<meta name="naver-site-verification" content="fed1..." />  <!-- deluxo용 신규 -->
<meta name="google-site-verification" content="pYiK..." />
```
- 두 verification 메타 공존 가능, 기존 ricorico용은 절대 삭제하지 말 것

### 사이트맵 운영 메모
- Tistory는 robots.txt 직접 수정 불가 (시스템 파일)
- 대신 GSC + 네이버 서치어드바이저에 `sitemap.xml` URL 직접 제출이 표준
- 재제출 시 **삭제 X, 동일 URL "제출" 한 번 더 클릭** (덮어쓰기로 재크롤 트리거)

### URL 검사
- 포스트 페이지: "사용자/Google 표준 URL 둘 다 해당사항 없음" → 색인 안 됐을 때 정상 메시지 (canonical 누락 아님)
- 홈만 정상 인식

### 진단 결론
- **canonical 충돌 가설 기각** ("중복, Google에서 선택한 표준이 사용자와 다름" 사유 0건)
- 단일 원인: **신생 도메인 권위 부족 + 콘텐츠 신호 부족** → Google이 평가 보류
- D+18에 색인 0은 정상 범위지만 가속 신호 필요

### 5/13 당일 추가 조치
- GSC URL 검사 색인 요청 5편 추가 신청

### Robots.txt 차단 1건 (GSC 메일)
- URL: `https://ricorico.tistory.com/search/{search_term_string}`
- 원인: Tistory가 `/search/*`를 자동 차단(시스템 설정), `{search_term_string}`은 SearchAction 스키마의 URL 템플릿 리터럴

## 9. 의사결정 변경 — ricorico 메인 전환 (옵션 A 채택, 2026-05-26)

### 결정 배경
- D+30 데이터로 **deluxo 메인 시나리오 작동 안 함 확정** (색인 0, 노출 0, 24일간 변화 없음)

### 검토된 3가지 옵션과 결정

| 옵션 | 내용 | 채택 여부 | 사유 |
